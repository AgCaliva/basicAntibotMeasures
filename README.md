# basicAntibotMeasures
This repository will contain snippets and code that will detect the most common boting/automation methods in games and others

I have published this snipped in Ankama discord but they dont seem to be willing to implement some anticheat (employees boting probably)

But this is useful for other games too.

## Instructions
### Install requirements:
pip install -r requirements.txt

### Open the console and run the detection code:
python initDetection.py

### Open new console and test detection:
python mouseKeyboardAutomationSample.py
